# POPQ ERD 캡처용 페이지

`index.html`을 브라우저로 열면 됩니다.

- **핵심 관계도**: PPT 한 장에 넣기 좋은 주요 테이블과 관계선
- **전체 테이블**: DOGO 엔티티 기준 27개 테이블 전체
- **관계선 숨기기**: 설명 카드만 깔끔하게 캡처할 때 사용
- **마우스 자유 배치**: 카드를 드래그하면 관계선도 함께 이동하며 배치는 자동 저장
- **배치 초기화**: 현재 화면의 모든 카드를 원래 격자 위치로 복원
- **PPT 캡처 모드**: 상단 도구를 숨겨 구성도만 표시하며, `H` 키로 원래 화면 복귀
- **전체 화면**: 브라우저 UI를 최소화해 캡처할 때 사용

POPQ Flyway 마이그레이션 기준 전체 49개 테이블을 반영했습니다. 각 카드에는 테이블명과 비전공자도 이해하기 쉬운 짧은 한국어 설명만 표시합니다.
