## 판매자·소비자 데이터 격리 점검

- 앱 application ID와 보안 세션 저장소는 판매자·소비자 앱이 서로 다르다.
- 서버 사용자 테이블은 공통 계정 원장을 사용하지만 API 역할을 `SELLER/ADMIN`과 `CUSTOMER`로 구분한다.
- 판매자 데이터는 활성 `StoreMember`와 요청 `storeId`를 매번 함께 검증한다.
- 주문·상품·사업장은 모두 선택된 사업장 소유 관계를 다시 검사한다.
- 따라서 같은 사용자 DB를 사용해도 소비자 세션이 판매자 API에 들어오거나 다른 판매자의 사업장을 수정할 수 없다.
